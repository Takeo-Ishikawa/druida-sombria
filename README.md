# Druida Sombria — Godot 4.7

Protótipo independente de animação esquelética 2D da **Druida da Floresta Sombria**.

## Estado

Repositório inicializado. A versão funcional do protótipo (com sprites e cenas) foi entregue como arquivo ZIP nesta conversa e ainda precisa ser importada para o repositório.

## Importar a versão Godot 4.7

1. Extraia `druida_sombria_godot_47.zip`.
2. Copie o conteúdo da pasta `druida_sombria_godot_47/` para a raiz deste repositório (não mantenha uma pasta extra).
3. Faça commit e push.
4. Abra `project.godot` no Godot 4.7 e pressione F5.

## Objetivos

- Preservar a identidade visual da ilustração de referência;
- Manter as peças gráficas independentes e transparentes;
- Aprimorar `Skeleton2D`, `Bone2D`, articulações e animações;
- Experimentar repouso, caminhada e ataque ritual sem alterar outros projetos.

## Observação

O protótipo é experimental, e sua execução no editor ainda precisa ser validada.
