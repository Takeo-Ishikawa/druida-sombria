# Pose neutra corrigida — instruções de publicação

O código de exibição já está integrado a `scripts/main.gd`. O projeto mantém os sprites antigos para estudo das articulações.

A versão artística final da pose neutra é uma imagem RGBA única chamada `druida_pose_neutra.png`, preparada nesta conversa e presente no pacote ZIP da versão corrigida.

**Para mostrá-la no GitHub Pages:** adicione o arquivo `assets/pose/druida_pose_neutra.png` ao repositório usando o GitHub (Add file > Upload files) ou copiando-o para o projeto local e executando `git add .`, `git commit`, `git push`.

Sem esse arquivo, o projeto usa um recorte provisório de `reference/ficha_original.png`, para evitar mostrar automaticamente a montagem antiga fragmentada.

Teclas: **1** nova pose estática, **2** caminhada do rig antigo (ainda com junções defeituosas), **3** gesto ritual do rig antigo. A pose neutra ainda **não foi separada em peças**. Essa será uma etapa posterior.
